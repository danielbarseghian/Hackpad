# Hackpad

Hello everyone! This is my Hackpad mission project.

I built this project in around **12 hours**. It took longer than expected because I ran into a lot of confusion along the way and had to restart several times. I wanted everything to be as good as I could make it.

This was also my **first time designing a PCB and creating 3D models in Fusion 360**. I really enjoyed the process. The Fusion part was sometimes frustrating because I spent a lot of time researching, waiting, and redoing things, but I think once I become more experienced it will be even more fun.
